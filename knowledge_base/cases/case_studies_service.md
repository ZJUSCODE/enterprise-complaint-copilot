# 客诉案例库（常规服务场景）

> 高频、可复用的处理范例。每条标注：处理路径、关键动作、结果。

## 案例 S-001 7 天无理由退货

**场景**：用户购买衣服 3 天后想退货（尺码不合），吊牌齐全未穿着。
**处理**：确认订单在 7 天内 + 商品不影响二次销售 → 引导申请售后 → 免费上门取件 → 验收后 48 小时退款。
**关键动作**：核对吊牌/未穿着；运费险覆盖则引导理赔。
**结果**：用户满意，退款 2 天到账。

## 案例 S-002 生鲜部分坏损

**场景**：用户收到一箱芒果，5 个碰伤（共 12 个）。
**处理**：核实坏损照片 → 坏损率约 40% → 按 40% 比例退款 → 原路退回。
**关键动作**：按实付金额核算；提醒剩余芒果尽快食用。
**结果**：退款到位，用户接受。

## 案例 S-003 物流延误安抚

**场景**：用户快递 5 天未更新，情绪激动。
**处理**：先共情致歉 → 核实轨迹（中转异常）→ 说明原因 + 预计时间 → 补偿 10 元券 → 48 小时跟进提醒。
**关键动作**：主动设置跟进，不让用户反复催。
**结果**：次日物流恢复，用户撤诉。

## 案例 S-004 3C 拆封质量问题

**场景**：用户购买手机使用 5 天后出现屏幕花屏，要求退货。
**处理**：收集故障描述 + 照片 → 判断属性能故障（非人为）→ 15 天内质量问题换货 → 引导走换机流程 + 厂家保修联动。
**关键动作**：区分性能故障 vs 人为损坏；SN 记录。
**结果**：换新机成功。

## 案例 S-005 发票问题

**场景**：用户申请企业发票，税号填错。
**处理**：未开票 → 指导修改抬头税号 → 重新提交 → 开具成功邮件推送。
**关键动作**：开票前核对四项信息。
**结果**：30 分钟解决。

## 案例 S-006 会员权益未到账

**场景**：用户开通 PLUS 会员后免运费券未到账。
**处理**：核实开通记录 → 确认发放延迟 → 手动补发权益 + 致歉。
**关键动作**：查开通时间与权益发放状态。
**结果**：补发成功。

## 案例 S-007 换货缺货

**场景**：用户申请换货，同款缺货。
**处理**：48 小时内审核通过 → 发现缺货 → 24 小时内联系用户三选一（退款/等补货/换同类）→ 用户选退款 + 5 元券。
**关键动作**：禁止默认等待，主动给选项。
**结果**：用户选退款，闭环。

## 案例 S-008 保价退款

**场景**：用户购买后 3 天发现同 SKU 降价 80 元，申请差价。
**处理**：核对同一 SKU 当前售价 → 确认在 15 天保价期 → 差价原路退回。
**关键动作**：核对同 SKU 同活动身份；排除优惠券组合差异。
**结果**：差价到账。

## 案例 S-009 快递破损补发

**场景**：用户收到陶瓷花瓶，外包装完好但瓶身碎裂。
**处理**：提供开箱视频 → 判断运输致损（包装缺陷）→ 免费补发 + 换加固包装 → 同步物流报备。
**关键动作**：外包装完好≠商品完好，需开箱证据。
**结果**：补发到货完好。

## 案例 S-010 用户要删个人信息

**场景**：用户注销账号并要求删除全部个人信息。
**处理**：引导自助注销 → 登记删除请求 → 48 小时内提交数据管理组 → 处理完成回执。
**关键动作**：留痕 + 告知删除不可逆。
**结果**：按流程完成。

## 案例 S-011 优惠券补偿

**场景**：大促系统卡顿导致用户下单失败，错过优惠价。
**处理**：核实订单记录 → 确认系统问题 → 补偿无门槛券 20 元 + 协助重新下单。
**关键动作**：补偿匹配问题等级。
**结果**：用户重购成功。

## 案例 S-012 老用户关怀

**场景**：60 岁用户不会申请退货，电话求助。
**处理**：全程人工协助 → 电话中核对订单信息 → 代提交申请 → 预约上门取件。
**关键动作**：无障碍通道，简化举证。
**结果**：退货完成，用户感谢。

## 案例 S-013 赠品缺失

**场景**：用户购买化妆品，赠品小样缺失。
**处理**：核实出库记录 → 确认漏发 → 补发赠品 + 致歉。
**关键动作**：赠品按实际价值补偿，不按主商品。
**结果**：赠品补发。

## 案例 S-014 跨境被税咨询

**场景**：用户海淘商品被税，询问能否退税。
**处理**：核对贸易方式（个人行邮）→ 说明行邮税政策 + 提供申报单 → 解释避税方式（合并订单/选保税仓）→ 不承诺退税。
**关键动作**：先确认贸易方式再答复。
**结果**：用户理解。

## 案例 S-015 好评返现举报

**场景**：用户举报商家诱导好评返现。
**处理**：登记举报 → 核实商家聊天记录 → 确认违规 → 商家处罚（扣分 + 限制资源）→ 回执用户。
**关键动作**：平台严禁好评返现，举报必查。
**结果**：商家被处罚。

## 案例 S-016 换货二次坏损

**场景**：用户换货后再次收到破损商品。
**处理**：确认二次坏损 → 直接升级主管 → 全退 + 30 元券 → 同步品控排查同批次。
**关键动作**：二次坏损不再简单补发，升级排查。
**结果**：退款到位，批次排查。

## 案例 S-017 宠物粮变质

**场景**：用户购买的猫粮发现有虫。
**处理**：按食品 A 级 → 取证（照片+批次）→ 全额退款 + 赔偿（授权内）→ 批次下架排查。
**关键动作**：宠物主粮按食品标准；批次溯源。
**结果**：退款赔偿完成，批次下架。

## 案例 S-018 课程质量申诉

**场景**：用户购买视频课程，发现缺少承诺的章节。
**处理**：核实课程目录与承诺内容 → 确认缺课 → 按缺失比例退款或补偿 → 同步内容团队补录。
**关键动作**：数字内容质量问题可申诉，非一律不退。
**结果**：按比例退款。
