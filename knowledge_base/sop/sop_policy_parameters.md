# 政策参数总表

> 各品类售后政策的量化参数（窗口/赔付/举证/时效/运费/风控/授权），客服与 AI Copilot 处理时直接引用。
> 生效日期：2026-07-01 · 版本：v1.0 · 维护人：售后运营部 · 风控合规部

## 3C数码 参数表

| 维度 | 参数 |
|---|---|
| 无理由退货 | 7 天，未激活/未拆封；已激活仅性能故障可退 |
| 质量问题 | 7 日退换修 / 15 日换修 / 保修期厂家免费维修 |
| 赔付标准 | 质量问题全退+运费平台承担；人为损坏不赔 |
| 举证要求 | SN、故障照片、开箱视频；性能故障需官方检测 |
| 处理时效 | 首响 2h，质检 3 个工作日（送检） |
| 运费规则 | 质量问题平台承担；无理由用户承担 |
| 风控提示 | SN 不符拒退；高货值需检测单；激活即贬值 |
| 客服授权 | 一线 500 元内；超 2000 元需主管+质检报告 |
