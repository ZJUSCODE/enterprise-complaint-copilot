# 仓库验收与退货质检 SOP

> 适用范围：退货商品到达仓库后的验收、质检、判定与异常处理。
> 生效日期：2026-07-01 · 版本：v1.6 · 维护人：仓储物流部 + 质检中心

## 1. 验收流程

1. **签收登记**：退货包裹签收 → 系统登记运单号与签收时间。
2. **外观检查**：外包装是否完好，破损件拍照留证。
3. **开箱核验**：核对商品与退货单（SKU/数量/附件/SN）。
4. **质检判定**：按品类质检标准判定（完好/瑕疵/损坏/调包）。
5. **结果录入**：验收结果录入系统（通过/不通过+原因），触发退款或客服跟进。

## 2. 验收时限

- 签收后 48 小时内完成验收（生鲜类问题件优先）。
- 验收超时的工单自动预警，客服跟进催办。
- 大促期间可延长至 72 小时（需公告）。

## 3. 验收标准

| 品类 | 验收要点 |
|---|---|
| 3C | SN 与出库一致、外观、配件齐全、是否激活 |
| 服饰 | 吊牌、洗涤痕迹、穿着痕迹、配件 |
| 家居 | 完整性、破损、安装痕迹 |
| 美妆 | 密封、开封状态、容量 |
| 食品 | 保质期、包装完整性（问题件留样） |
| 虚拟 | 核销状态（无需实物验收） |

## 4. 异常处理

- **SN 不符/调包嫌疑**：暂停退款 → 拍照留证 → 转风控 → 客服联系用户。
- **配件缺失**：记录缺失项 → 客服协商折价或补件。
- **使用痕迹**：记录 → 客服沟通（按规则折价或退回）。
- **运输损坏（退货途中）**：拍照 → 平台承担（用户无责），按规则补退。
- **验收争议**：提供验收照片/视频给用户，升级主管复核。

## 5. 与客服联动

- 验收不通过 → 系统自动生成跟进工单 → 客服 24 小时内联系用户。
- 客服需用验收证据（照片）沟通，避免空口判定。
- 用户不认可验收结论 → 升级质检复核（24 小时）。

## 6. 防损与审计

- 验收环节拍照留证率 100%（关键商品）。
- 每周抽检验收质量（复验 5% 退货单）。
- 验收差错（误判）纳入质检考核，按月复盘。
