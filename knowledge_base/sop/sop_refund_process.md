# 退款流程与资金安全 SOP

> 适用范围：全部退款场景（退货退款、仅退款、赔付退款、线下退款）。
> 生效日期：2026-07-01 · 版本：v1.7 · 维护人：财务结算部 · 售后运营部

## 1. 退款方式总览

| 支付方式 | 退款路径 | 预计到账 |
|---|---|---|
| 余额/零钱 | 原路退回余额 | 实时 |
| 储蓄卡 | 原路退回银行卡 | 1-3 个工作日 |
| 信用卡 | 原路退回信用卡 | 3-5 个工作日 |
| 花呗/白条等 | 原路退回消费信贷 | 3-5 个工作日 |
| 组合支付 | 按支付比例拆分原路退回 | 取最长路径 |

退款一律**原路退回**，不得转个人账户；确需线下退款的必须走财务审批流程。

## 2. 退款金额核算

- 按**实付金额**退款（实付 = 标价 - 优惠券 - 满减 - 积分抵扣 + 运费）。
- 优惠券已使用的：券未过期退回券，过期按实付退；部分退款时按比例分摊。
- 积分支付部分按积分原路退回（1 积分 = 1 分钱）。
- 运费在「平台责任场景」一并退（质量问题、错发、漏发、破损），无理由退货不退运费。
- 退款金额有争议的，客服需给用户列出核算明细，禁止含糊其辞。

## 3. 退款时效承诺

- 退货退款：仓库验收通过后 48 小时内发起，按渠道到账。
- 仅退款（无需退货）：审核通过后 24 小时内发起。
- 赔付退款（先行赔付）：审批通过后 24 小时内发起。
- 线下退款：财务审批流程 3 个工作日内完成打款。

客服必须在首次沟通时告知预计到账时间，避免用户因等待焦虑重复催促。

## 4. 退款失败处理

退款失败（原路退回被银行/渠道拒绝）的处理流程：

1. 系统检测失败自动通知客服，客服 24 小时内联系用户核实支付账户状态。
2. 常见原因：银行卡注销/挂失、信用卡过期、账户状态异常、渠道限额。
3. 处理：引导用户更新支付方式（绑定新卡）重新发起；或切换等额退款方式（需用户确认）。
4. 连续失败 2 次以上的，升级财务专员人工处理，禁止反复自动重试（可能触发渠道风控）。

## 5. 资金安全红线

- 禁止客服个人账户代收代付任何款项。
- 线下退款必须：主管审批 + 财务复核 + 系统留痕，三要素齐全。
- 退款金额与实际应退金额不一致时，系统拦截并转财务核查。
- 涉及「协助用户套现」（退款不退货、虚开赔付）的，一律上报风控，按舞弊处理。
- 每笔退款可追踪：工单号、订单号、退款流水号、操作人、审批人，形成闭环审计链。

## 6. 争议与客服权限

| 场景 | 客服权限 |
|---|---|
| 常规退款（规则内） | 直接操作 |
| 超额退款（超规则 20% 内） | 主管审批 |
| 超额退款（超规则 20% 以上） | 经理审批 + 财务备案 |
| 线下退款 | 财务审批 |
| 疑似欺诈/套现 | 拒绝并上报风控 |

客服在权限内直接处理，超权限先申请后答复——「先斩后奏」式承诺会直接违反资金安全红线。
