# 退款流程与资金安全 SOP

> 适用范围：退款全流程（申请、审核、打款、失败处理、特殊退款）、资金安全红线。
> 生效日期：2026-07-01 · 版本：v2.3 · 维护人：财务结算组 + 售后运营部

## 1. 退款全流程

申请 → 审核（自动/人工）→ 退货（如需）→ 验收（如需）→ 打款 → 到账确认 → 工单闭环。

| 环节 | 时限 | 说明 |
|---|---|---|
| 申请提交 | 实时 | 用户端发起 |
| 自动审核 | 实时 | 极速退款/低风险单 |
| 人工审核 | 24-48h | 高货值/高风险 |
| 仓库验收 | 48h | 签收后起算 |
| 打款 | 验收后 48h | 原路退回 |
| 到账 | 余额实时 / 银行卡 1-3 工作日 / 信用卡 3-5 工作日 | 以渠道为准 |

## 2. 极速退款（自动退款）

- 适用：实付 ≤200 元、风险分低、证据齐全、无退货流程（生鲜/虚拟等）。
- 排除：高货值、风险标记、多次退款记录、类目敏感（3C/珠宝）。
- 自动退款后仍需跟进：商家侧责任认定、欺诈追回。

## 3. 退款失败处理

1. 用户反馈超时未到账 → 先查支付渠道流水（渠道路由、银行处理）。
2. 渠道已打款 → 安抚 + 告知预计到账日，设置跟进提醒。
3. 渠道打款失败（卡注销/冻结/限额）→ 联系用户更换收款方式（银行卡/余额），走线下退款审批。
4. 线下退款必须走财务审批 + 双人复核，禁止客服个人转账。
5. 疑难退款（跨渠道/历史订单）超 3 个工作日未解决 → 升级财务结算组。

## 4. 特殊退款

| 场景 | 规则 |
|---|---|
| 部分退款（仅退运费/差价） | 按实付核算，运费 ≤15 元 |
| 优惠券/积分订单 | 按实付比例分摊，券不退还 |
| 分期订单 | 已还/未还分别处理，未还由渠道冲销 |
| 跨境订单 | 15-30 个工作日到账，汇率差平台承担 |
| 商家已退款但平台重复退 | 追回差额，防止重复赔付 |
| 用户要求退到非原账户 | 仅限卡注销等特殊场景，需身份核验 |

## 5. 资金安全红线

- **禁止**：客服个人转账/现金退款、要求用户提供支付密码、诱导线下交易。
- 退款金额必须与系统记录一致，任何人不得手动改金额（改需审批+留痕）。
- 重复退款检测：同一订单只允许退一次，系统防重，人工复查。
- 退款台账每日对账，差异（长短款）当日上报。
- 疑似套现（仅退款不退货高频、新账号大额）：冻结退款 + 风控核查。

## 6. 对账与审计

- 每日自动对账（订单流水 vs 退款流水），差异预警。
- 每周人工抽检退款工单（≥5%），检查合规性。
- 每月出退款分析报告：退款率、退款原因分布、异常模式。

## 7. 话术要点

- 「您的退款我们已提交，预计 X 个工作日内原路退回，到账后会有通知。」
- 「银行卡注销的话，我们可以帮您变更收款账户，需要核验一下身份信息。」
- 禁止说「钱退不了」「我们也没办法」——退款失败一定有处理路径。
