## 3C数码 品类处理矩阵

| 问题类型 | 处理口径 |
|---|---|
| 无理由退货 | 未激活/未拆封支持 7 天无理由；已激活仅限性能故障 |
| 质量问题 | 7 日内退换修任选，8-15 日换修，保修期内厂家免费维修 |
| 拆封争议 | 拆封影响二次销售不支持无理由；质量原因拆封不受影响 |
| 外观瑕疵 | 签收 24 小时内反馈受理，超时不受理外观申诉 |
| SN 不符 | 退货验机 SN 与出库不符即拒退，记录异常并转风控 |
| 保修期内故障 | 引导厂家官方售后或平台代送修，保留维修工单 |
| 人为损坏 | 进水/摔落/拆修不在保修，需官方检测定性 |
| 激活码失效 | 核实后补发正确码或退款，48 小时内处理 |
| 充电器/配件缺失 | 核实出库记录，确认漏发则补发 |
| 系统/软件问题 | 先引导官方技术支持，硬件问题再走售后 |
| 发票需求 | 按发票流程开具，3 个工作日推送 |
| 高货值退货 | 超 2000 元需质检报告或检测单，主管复核 |
| 二手/翻新成色 | 成色不符按描述不符全退+运费平台承担 |
| 延保服务 | 按服务卡条款执行，纠纷转延保服务商 |
| 以旧换新 | 旧机回收核验后抵扣，争议转回收服务商 |

> 通用原则：所有品类统一适用退款时效（验收后 48h 打款）、投诉升级路径（POL-025）、赔偿管控（POL-047）与客服红线（POL-032）。

| 禁运品 | 核实海关政策，无法寄送按规则退款 |
| 保税仓商品 | 含税价销售，退税费按规则 |
| 海外售后 | 协调品牌海外售后或平台代处理 |
| 物流异常 | 国际物流时效长，按跨境时效标准 |
| 申报单据 | 保留原始报关单据，协助补办 |

> 通用原则：所有品类统一适用退款时效（验收后 48h 打款）、投诉升级路径（POL-025）、赔偿管控（POL-047）与客服红线（POL-032）。
