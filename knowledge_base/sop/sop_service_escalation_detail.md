# 投诉升级与舆情处置执行细则

> 适用范围：L3/L4 重大投诉、监管投诉、媒体舆情、群体事件、安全事件的升级与处置执行细则。
> 生效日期：2026-07-01 · 版本：v2.3 · 维护人：客诉中心 + 法务 + 公关

## 1. 投诉分级操作卡片

### L1 一般咨询（一线客服）
- 特征：无情绪、问信息（政策/物流/发票）。
- 动作：直接解答，24h 内回复。
- 禁止：升级占用高层资源。

### L2 普通投诉（一线+组长）
- 特征：明确不满、诉求在规则内（延误/瑕疵/退款慢）。
- 动作：12h 给方案、48h 闭环；可给 10-50 元券或授权内补偿。
- 升级触发：48h 内 3 次催促未回复、金额超 500 元。

### L3 重大投诉（主管）
- 特征：金额超 1000 元、威胁监管/媒体、多次未解决、涉及人身安全。
- 动作：4h 响应、24h 给方案；主管亲自处理；同步风控+法务。
- 闭环：主管签字 + 48h 回访。

### L4 危机投诉（客诉经理牵头专项组）
- 特征：已投诉 12315/工商/食药监、媒体舆情、群体投诉（10 人+）。
- 动作：1h 响应；专项组（客诉+法务+公关+业务）；24h 出初步方案。
- 闭环：法务全程参与 + 管理层汇报。

## 2. 舆情处置流程（媒体/短视频/微博）

1. **监测发现**：舆情系统/客服转报 → 10 分钟内升级公关 + 客诉经理。
2. **事实核查**：2h 内还原事实（订单、记录、证据），明确责任。
3. **用户沟通**：客诉经理 2h 内直接联系用户，给实质方案。
4. **公关动作**：官方回应口径（统一）、平台侧处置（不强行删帖）、必要时公开说明。
5. **复盘**：72h 内出复盘报告，输入流程改进。

红线：
- 一线客服禁止对媒体发表任何言论。
- 禁止花钱删帖/买公关（违规且无效）。
- 验真结论必须真实，禁止为平息舆论出具虚假结论。

## 3. 监管投诉处理（12315/市场监管局/食药监）

1. **响应**：法务 1h 介入，客服提供完整记录（订单/沟通/处理过程）。
2. **整改**：24h 内出整改方案并执行。
3. **配合**：按要求提供材料、接受调解，禁止对抗式回应。
4. **归档**：监管工单独立建档，处理结果留痕。

## 4. 群体事件处置（10 人以上同问题）

1. **识别**：同 SKU/同区域/同问题 10 人以上投诉 → 自动标记。
2. **成立专项组**：客诉经理 2h 内牵头，成员：客诉+品控+供应链+法务。
3. **方案统一**：梳理受影响清单，制定统一方案（换/退/赔标准一致），法务审核。
4. **执行**：批量主动触达（短信/公告），专区客服承接。
5. **复盘**：根因分析（品控/供应链/系统），7 天输出报告。

## 5. 安全事件处置（人身/健康/财产）

- 一律 L3+，法务参与。
- 食品中毒/儿童伤害/电器起火：2h 内上报管理层 + 召回评估。
- 用户损失：先安抚+登记损失清单，金额由法务/经理核定，一线不报价。
- 涉及报警（诈骗/盗刷）：出具交易流水与证明材料。

## 6. 升级后沟通规范

1. 接手人 30 分钟内确认接手，工单记录处理计划。
2. 首次沟通表明身份与权限，给明确方案与时限。
3. 禁止推诿话术（「不归我管」「我做不了主」）。
4. 升级前充分了解历史（订单、投诉记录、情绪状态），做好预案。
5. 每次沟通留痕（文字/录音），涉及承诺必须记录。

## 7. 高频争议场景预案

| 场景 | 标准动作 | 禁止 |
|---|---|---|
| 用户扬言曝光 | 10 分钟升级，不刺激 | 说「你去曝光啊」 |
| 用户要求领导 | 直接转主管，不拖延 | 「领导不在」 |
| 用户反复投诉 | 查历史，换方案或升级 | 重复同样话术 |
| 用户索要高额赔偿 | 按权限上限+规则核算 | 一口回绝/随口承诺 |
| 用户情绪失控 | 先共情，再转接 | 挂机/对骂 |
| 群体性诉求 | 统一口径+专项组 | 各客服各说各话 |
| 律师/媒体介入 | 转法务/公关 | 一线继续对接 |

## 8. 话术要点

- 「您的问题我已经升级给主管亲自处理，24 小时内一定给您明确答复。」
- 「您提到的维权渠道是您的权利，同时我们也会以最快速度解决，请您再给我们一次机会。」
- 「我们已成立专项小组处理这批问题，会给所有受影响的用户统一方案，请您耐心等待。」
- 禁止说「您爱投诉就投诉」——任何一句都可能把 L2 变成 L4。
