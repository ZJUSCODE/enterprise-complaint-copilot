# 美妆个护品类售后 SOP

> 适用范围：护肤、彩妆、香水、洗护、口腔护理、身体护理、美容仪器等。
> 生效日期：2026-07-01 · 版本：v1.8 · 维护人：售后运营部 · 品控部

## 1. 退换货总则

- 美妆个护类**未拆封**商品支持 7 天无理由退货（需外包装完好、封条完整）。
- **已拆封**商品仅在两种情况受理退换：① 质量缺陷（变质、分层、结块、异味）；② 过敏反应（48 小时内反馈并有凭证）。
- 美妆商品为卫生敏感类，**拆封即视为影响二次销售**，这是与普通商品的核心差异。

## 2. 过敏投诉处理（重点）

过敏是美妆类最敏感投诉，处理标准流程：

1. **时限**：自签收起 48 小时内反馈（以聊天记录/工单时间为准）。
2. **凭证**：过敏部位照片 + 商品实物照片 + 购买订单，三要素缺一不可。
3. **定性**：客服不判定「是不是过敏」，只核验凭证完整性；是否成立由品控/客服主管判断。
4. **处理**：确认过敏 → 退货退款（运费商家承担）+ 可提供关怀补偿（10 元券）；不确认 → 协商补偿或转品控复核。

注意事项：
- 用户「使用后感觉刺激/发热」但无照片 → 先安抚，建议停用，观察 24 小时后再反馈。
- 用户「用了一周才说过敏」→ 超时限，婉拒退货，可协商优惠券补偿，但不承诺金额。
- 用户主张「假货致敏」→ 转品牌核实批次，一线不回应。

## 3. 质量缺陷判定

| 现象 | 判定 | 处理 |
|---|---|---|
| 分层/水油分离（保质期内） | 质量缺陷 | 退换，运费商家承担 |
| 结块/变干/异味（保质期内） | 质量缺陷 | 退换 |
| 颜色与页面色差明显 | 描述不符 | 退换，运费商家承担 |
| 质地与描述不符（如宣称清爽实际油腻） | 主观感受 | 协商处理，不承诺退货 |

## 4. 保质期与临期管理

- 商品剩余保质期不足 3 个月的（保质期 3 年以上的品类放宽至不足 6 个月）必须在商品页**显著标注「临期」**。
- 未标注临期但实际临期的 → 用户可主张描述不符，退货退款运费商家承担。
- 已过期商品收到即投诉的 → 按食品安全级别处理：全额退款 + 赔偿，同步下架同批次。

## 5. 美容仪器类

- 美容仪器（洁面仪、射频仪、脱毛仪）按 3C 规则处理：7 日性能故障可退换，保修期内免费维修。
- 仪器类商品拆封后同样不支持无理由退换（卫生原因）。
- 医疗器械类（如有）需提示资质，投诉功效问题引导至说明书适用范围，不承诺医疗效果。

## 6. 小样与赠品

- 小样/旅行装拆封后不支持退换；未拆封可随主商品退。
- 赠品破损按赠品价值补偿，不按主商品价值补偿（见《售后SOP》17.1）。
- 「送的小样过敏」→ 小样过敏可退主商品（按过敏流程），或只补偿小样价值，视用户意愿。

## 7. 话术要点

- 「非常抱歉给您带来不好的体验。为了帮您核实情况，麻烦提供一下过敏部位和商品的照片，我们会在 48 小时内为您处理。」
- 「化妆品拆封后是影响二次销售的，不过如果是过敏或质量问题，我们都会按规则为您处理。」
- 禁止说「我们的产品不可能过敏」「别人都没事」——这类话术会直接激化投诉。
