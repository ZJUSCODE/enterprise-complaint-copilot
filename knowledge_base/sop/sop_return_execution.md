# 退换货执行细则

> 适用范围：全部实物商品的退换货执行层面细则。与《售后SOP》总纲配套，本细则给出可执行的操作步骤、品类窗口明细与例外清单。
> 生效日期：2026-07-01 · 版本：v2.4 · 维护人：售后运营部

## 1. 退货受理前置检查（五步）

任何退货申请，客服必须先完成以下五步检查，缺一不可：

1. **订单核验**：确认订单号有效、状态为已签收（或配送中）、商品可售后（非已关闭/已仲裁）。
2. **时效核验**：计算签收时间 → 是否在对应窗口内（无理由 7 天 / 质量问题按三包 / 特殊品类按品类窗口）。
3. **状态核验**：商品是否被使用/激活/拆封（影响无理由 vs 质量路径判定）。
4. **类目核验**：是否属于不适用无理由类目（定制、鲜活、拆封影响二次销售、虚拟、临期）。
5. **风控核验**：用户风险分、退款频率、关联账号、历史赔付记录。

五步任一命中异常（超窗口/不适用类目/高风险），转入人工或升级流程，禁止自动放行。

## 2. 品类窗口明细表

| 品类 | 无理由窗口 | 质量窗口 | 特殊规则 |
|---|---|---|---|
| 3C 数码 | 7 天（未激活） | 7 日退换修/15 日换修/保修期修 | 激活即贬值；SN 核验 |
| 生鲜 | 不支持 | 签收 24h 内反馈 | 坏损率分级赔付 |
| 食品 | 不支持 | 按 A/B/C 分级 | 安全事件批次下架 |
| 服饰 | 7 天 | 按质量判定 | 吊牌完整未穿着 |
| 家居 | 7 天（定制除外） | 48h 结构性破损反馈 | 大件上门取件 |
| 美妆 | 7 天（未开封） | 过敏 48h 反馈 | 开封即贬值 |
| 母婴 | 7 天（未拆封） | 安全事件最高优先 | 3C 认证核查 |
| 宠物 | 主粮 7 天 | 变质按食品 A 级 | 活体按健康保障书 |
| 户外 | 7 天 | 功能问题核实 | 安全性能升级 |
| 虚拟 | 未使用可退 | 失效/发错可退 | 已使用不可退 |
| 二手 | 7 天（按成色描述） | 30 天质保期 | 成色不符全退 |
| 跨境 | 非质量不支持 | 7 天内申请 | 保留原包装+申报单 |

## 3. 退货物流执行

- **上门取件**：支持区域优先预约上门取件（免费），取件后生成退货物流单。
- **自行寄回**：不支持上门区域引导自行寄回，凭快递单号申请运费补偿（≤15 元，质量问题全额报销）。
- **大件退货**：平台安排大件承运上门取件，禁止引导用户自行联系物流。
- **生鲜/食品**：问题商品无需寄回（变质/坏损直接销毁或留样），避免二次运输。
- **拒收处理**：用户拒收的包裹自动触发退款流程，客服需跟进确认退款。

## 4. 仓库验收与退款触发

1. 仓库签收退货商品 → 48 小时内完成验收。
2. 验收通过 → 自动触发退款（原路退回）。
3. 验收不通过（损坏/配件缺失/SN 不符）→ 客服联系用户：
   - 轻微问题：协商折价退款。
   - 严重问题：商品退回用户或转质检。
   - SN 不符：按风控流程，记录异常。
4. 验收争议（用户不认可验收结论）：升级主管复核，必要时提供验收照片/视频。

## 5. 换货执行

- 换货审核 48 小时内，通过后 3 个工作日发出。
- 二次发货前必须质检确认，杜绝二次投诉。
- 换货缺货：24 小时内联系用户三选一（退款/等补货/换同类）。
- 换货运费：质量/错发平台承担；无理由用户承担（运费险覆盖走理赔）。
- 换新商品重新计算三包期与无理由窗口（从换新签收起算）。

## 6. 例外与红线

- **例外清单**（可给补偿）：大促批量异常、系统故障、商家失联、平台责任。
- **红线**（不可退）：超窗口无理由、已激活 3C、定制商品（无质量缺陷）、已使用虚拟商品。
- 红线场景被用户投诉的：**不硬顶**，解释规则 + 提供替代方案（券/积分/升级），避免升级成投诉。

## 7. 常见争议处理速查

| 争议 | 处理 |
|---|---|
| 用户坚持无理由退货但已拆封 | 解释规则，转质量路径评估；无质量问题给小额券 |
| 超 7 天要求无理由 | 解释窗口，质量路径仍开放 |
| 退货商品少配件 | 按验收结果协商折价 |
| 退货运费争议 | 按责任方判定，运费险覆盖走理赔 |
| 用户要求上门取件但区域不支持 | 解释 + 运费补偿兜底（≤15 元） |
| 换货缺货引发不满 | 主动三选一 + 小额券安抚 |
| 二次收货仍破损 | 直接升级，不再简单补发 |

## 8. 话术要点

- 「您的情况属于（无理由/质量问题/特殊类目），我帮您走对应流程，X 小时内给您答复。」
- 「这件商品已经拆封/激活，按规则不支持无理由退货，不过如果存在质量问题，我们一样会为您处理。」
- 「退货我们已安排上门取件，取件后 X 天内退款到账，请您留意。」
- 禁止说「我们店不支持退货」「退货要自己出运费」——按品类规则执行，不口头加码。
