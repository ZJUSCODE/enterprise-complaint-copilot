# 证据标准手册

> 适用范围：所有售后判责场景的证据采集、核验与留存标准。
> 目的：让"要什么证据、怎么判断证据有效"有统一标准，减少争议与职业索赔漏洞。
> 生效日期：2026-07-01 · 版本：v1.8 · 维护人：质检中心 + 风控合规部

## 1. 证据类型与有效性判定

| 证据类型 | 有效条件 | 常见无效情形 |
|---|---|---|
| 商品照片 | 自然光、含整体+特写、可辨识商品 | 模糊、网络图、PS、滤镜 |
| 开箱视频 | 连续完整、含面单信息、首次开箱 | 剪辑拼接、中途切换 |
| 物流证明 | 官方轨迹、红章证明、面单照片 | 截图无法核实 |
| 检测报告 | 正规机构、盖章、与商品对应 | 个人出具、无资质 |
| 就医凭证 | 正规医院、与症状对应 | 无诊断、非对应部位 |
| 聊天记录 | 含时间、账号、完整上下文 | 断章取义、截图编辑 |

## 2. 各场景证据要求明细

| 场景 | 必交证据 | 补充证据 | 免证情形 |
|---|---|---|---|
| 生鲜坏损 | 整体照+特写+面单 | 开箱视频（高价） | 整单变质（明显） |
| 食品过期 | 外包装（批次）+内物 | 购买记录 | 批次记录可查 |
| 3C 质量问题 | 故障描述+照片 | 官方检测报告 | 质检可复现 |
| 3C 外观瑕疵 | 24h 内照片 | 开箱视频 | — |
| 大件破损 | 破损照片+面单 | 开箱视频 | 当场拒收记录 |
| 少件 | 开箱视频 | 快递员在场证明 | 出库记录可查 |
| 丢件 | — | 物流轨迹 | 承运商确认 |
| 美妆过敏 | 过敏部位照+购买记录 | 就医凭证 | 48h 内反馈 |
| 母婴安全问题 | 商品照+批次 | 就医凭证 | 安全事件 |
| 假货质疑 | 品牌验真证据 | 官方鉴定 | 品牌方确认 |
| 活体死亡 | 开箱视频+兽医证明 | 死亡照片 | 当场确认 |
| 调包争议 | 验机记录+物流签收 | 全程轨迹 | SN 核验记录 |

## 3. 举证责任分配

- **质量/坏损/破损**：举证责任在平台/商家（用户提供初步照片即可，平台负责核实）。
- **人为损坏/调包**：举证责任在平台（需检测报告/验机记录）。
- **无理由退货**：只需确认时效与商品状态。
- **欺诈指控**：平台需完整证据链（出库/物流/签收/验收）。

原则：**存疑从用户**——无法定性的争议按有利于用户的方向处理，同时保留追偿权利。

## 4. 证据核验流程（防职业索赔）

1. **真伪核验**：照片/视频是否网络图（反向搜索）、是否重复使用（历史工单比对）、是否编辑（EXIF/PS 痕迹）。
2. **关联核验**：证据是否与订单对应（面单号、批次号、SN）。
3. **频次核验**：同账号/同地址/同手机号的历史索赔记录。
4. **行为核验**：短时间内多单同类型索赔、索赔金额集中、话术模板化。

命中可疑特征的工单：自动标记风控，转人工复核，24 小时内完成。

## 5. 证据留存与合规

- 所有证据随工单归档，保存至少 2 年（监管/司法需要）。
- 涉及个人信息的证据（照片含人脸、住址）按隐私规范处理，脱敏存储。
- 用户撤回授权或要求删除证据的：按数据删除流程处理（POL-024）。
- 证据不得用于工单处理以外的用途。

## 6. 免证与特例

- **明显事实**（整箱腐烂、肉眼可见的大面积破损）免详细举证，快速处理。
- **弱势用户**（老人、孕妇、残障）简化举证，人工协助补录。
- **平台责任明确**（系统超卖、批量错发）无需用户举证。
- **安全事件**（食品中毒、儿童伤害）证据从简，优先处理+法务备案。

## 7. 话术要点

- 「麻烦您提供一下 X 和 Y，我们核实后 24 小时内给您答复。」
- 「您提供的证据我们已经收到，正在核实，请稍等。」
- 「很抱歉，目前的证据暂时无法确认 X 情况，我建议您补充 Y，我们可以继续为您处理。」
- 禁止说「没证据就不能退」——证据不足时先登记+给补证路径，不直接拒绝。
