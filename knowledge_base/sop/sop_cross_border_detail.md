# 跨境与保税仓售后执行细则

> 适用范围：直邮、保税仓发货、海外仓、转运等跨境订单的售后执行。
> 生效日期：2026-07-01 · 版本：v1.9 · 维护人：跨境业务组 + 法务

## 1. 贸易方式区分（第一步必做）

跨境订单处理前**必须确认贸易方式**，不同方式规则差异巨大：

| 贸易方式 | 特点 | 售后规则 |
|---|---|---|
| 保税仓发货（1210） | 商品已入保税仓，含税价销售 | 质量问题可退，退货需入区申报 |
| 直邮个人行邮 | 从境外直发，个人物品清关 | 非质量不支持无理由，被税不代缴 |
| 海外仓直发 | 商品在海外仓，境内调拨 | 退货需退回海外仓，成本高 |
| 转运/代购 | 第三方转运 | 按平台规则+转运商责任判定 |

判断依据：订单页的「贸易方式」字段 + 物流单号类型。无法判断时查询订单系统。

## 2. 退货处理流程

1. 确认退货原因（质量问题 vs 其他）。
2. 质量问题：签收 7 天内申请，需提供完整外包装 + 报关单号。
3. 非质量问题：明确告知不支持（个人行邮/保税规则），可协商补偿。
4. 退货物流：指定承运（支持跨境退货的物流商），运费按责任方。
5. 退货申报：以「退货复进口」方式申报，保留原始报关单据。
6. 退款：退货确认后 15-30 个工作日到账（跨境结算周期）。

## 3. 关税与税费

- **个人行邮**：税额以海关核定为准，平台不代缴代退，提供完税证明与申报单。
- **保税仓**：含税价销售，无额外税费。
- **被税争议**：说明行邮税政策（50 元起征点等），提供单据，不承诺退税。
- **退货关税**：责任方承担；商家/平台责任时平台垫付。
- 用户要求避税建议：合并订单、选择保税仓商品、控制单件金额。

## 4. 物流与时效

- 跨境物流时效：直邮 7-20 个工作日，保税 3-7 个工作日（页面承诺为准）。
- 延误判定：按跨境时效标准（较国内放宽），异常（超 15 工作日无轨迹）启动调查。
- 清关异常：海关查验/扣留 → 协助补件/申报，税费按责任方。
- 丢失赔偿：按跨境保险或货值赔付，流程 15-30 个工作日。

## 5. 汇率与金额

- 跨境订单以外币计价的：退款按原支付币种结算。
- 汇率波动差额：平台承担（用户不亏）。
- 优惠券/满减：按实付金额退款，券不退还。

## 6. 特殊品类

| 品类 | 跨境特殊规则 |
|---|---|
| 美妆 | 需中文标签；无中文标签属违规（可投诉） |
| 保健品 | 需进口许可；功效投诉按说明书 |
| 3C | 需 CCC 认证（部分）；无认证违规 |
| 食品 | 需中文标签+进口检验检疫证明 |
| 母婴 | 需中文标签；奶粉需配方注册 |
| 珠宝奢侈品 | 需鉴定证书；假货按品牌验真 |

## 7. 风控

- 跨境是**洗钱/套利/假货投诉**高发区：
  - 同一地址频繁跨境退货 → 风控标记。
  - 「假货」投诉批量出现 → 品牌验真 + 供应链排查。
  - 高价值跨境商品退货 → 验真后处理。
- 跨境售后单据不全（无报关单/无中文标签）的投诉，优先核实商家合规资质。

## 8. 话术要点

- 「您的订单是个人行邮方式，非质量问题不支持无理由退货，这是跨境商品的规定，请理解。」
- 「被税的部分以海关核定为准，我把完税证明和申报单发您，后续可以凭单咨询海关。」
- 「跨境退货需要走指定物流，运费按责任方承担，退款一般 15-30 个工作日到账。」
- 禁止说「跨境商品都不退」——质量问题必须受理；禁止承诺「退税」「包税」。
