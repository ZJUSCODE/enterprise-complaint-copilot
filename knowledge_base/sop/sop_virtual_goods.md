# 虚拟商品与数字内容售后 SOP

> 适用范围：充值卡/礼品卡、会员服务、在线课程、软件授权、数字资料、游戏道具等无实物商品。
> 生效日期：2026-07-01 · 版本：v1.4 · 维护人：数字业务售后组

## 1. 虚拟商品特殊性

虚拟商品**一经核销/使用/下载即不可逆**，这是与实物商品最大的差异。因此售后处理的核心是：**先判断是否已被使用，再决定是否可退**。

分类：
- **卡券类**（充值卡、礼品卡、优惠码）：未绑定/未使用可退。
- **会员服务类**（视频/音乐/网盘会员）：未激活可退，已激活按月折算或不可退。
- **内容类**（在线课程、电子书、资料包）：一旦下载/播放即不可退（行业惯例）。
- **软件授权类**（激活码、订阅）：未激活可退，已激活仅限功能缺陷。
- **游戏类**（点券、道具、账号服务）：点券未使用可退，道具已使用不可退。

## 2. 退换判定标准

| 情形 | 处理 |
|---|---|
| 未使用/未激活 | 支持退款，原路退回 |
| 已激活但发错（错充、错码） | 核实后补发正确商品或退款 |
| 已使用后要求退 | 一般不支持，可协商（如会员剩余时长折算） |
| 激活码失效/被占用 | 核实后补发新码或退款，48 小时内处理 |
| 内容质量问题（课程缺课、资料损坏） | 平台介入核实，确认后按比例退或补发 |
| 疑似盗刷购买 | 按账号安全流程处理（见 POL-031） |

## 3. 关键流程

1. **核销核验**：通过订单系统核验商品是否已被使用/激活/下载，这是第一优先动作。
2. **证据要求**：用户主张未使用，需提供账号状态截图；平台侧核验核销记录为准。
3. **时效**：虚拟商品售后时效 7 天内受理，充值类 48 小时内优先处理。
4. **重复索赔风控**：同一账号多次"未使用退款"后再次购买又退款的，转人工复核（虚拟商品是套利高发区）。

## 4. 会员与订阅类细则

- 会员自动续费：用户要求关闭的，立即引导自助关闭 + 协助操作，不产生额外扣费。
- 续费后立即取消：按各平台规则，支持全额退续费款的引导申请（通常 48 小时内）。
- 会员权益未到账：核实开通记录，确认后补发权益或顺延有效期。

## 5. 教育/内容类细则

- 课程未开课全额退；开课后按已学课时折算（平台规则），协商一致可部分退款。
- 直播课错过可看回放，回放缺失影响学习的，按缺失比例补偿。
- 资料包下载失败/损坏：核实后重新提供下载链接，重复 2 次仍失败可退。

## 6. 游戏与账号安全

- 游戏点券/道具误充：未使用可申请退还，已使用（合成/消耗）不支持。
- 账号被盗后购买虚拟商品的：按盗刷流程（POL-031），核实后退款并冻结。
- 虚拟商品交易严禁私下交易（绕平台），由此产生的纠纷平台不介入。

## 7. 话术要点

- 「虚拟商品一经使用就无法退回，这是平台规则；不过您的情况我帮您核实一下是否还能处理。」
- 「您的会员剩余时长还有 X 个月，我可以帮您申请按剩余价值折算，您看可以吗？」
- 禁止说「虚拟商品一律不退」——未使用/发错/失效等场景必须受理。
