# 防欺诈与风控手册

> 适用范围：职业索赔、套现、调包、诈骗识别与处置。
> 生效日期：2026-07-01 · 版本：v1.7 · 维护人：风控合规部

## 1. 欺诈类型与识别特征

| 类型 | 典型特征 | 风险等级 |
|---|---|---|
| 职业索赔 | 同地址多账号、批次/法规话术模板、专挑临期/瑕疵 | 高 |
| 套现（仅退款） | 新账号、无理由仅退款、拒绝退货、金额集中 | 高 |
| 调包退货 | 退货 SN/成色与出库不符、验机异常 | 高 |
| 伪造证据 | 网络图、PS、重复使用历史照片 | 高 |
| 团伙操作 | 同 IP/同设备/同地址多账号、时间集中 | 高 |
| 电信诈骗（冒充客服） | 要求转账/手续费/解冻 | 高（用户侧） |
| 薅羊毛 | 利用活动规则漏洞批量下单 | 中 |

## 2. 识别流程

1. **规则引擎**：订单/售后单自动过风控规则（频率、金额、关联、特征词）。
2. **人工复核**：命中规则的工单转人工，24 小时内完成。
3. **关联分析**：手机号/地址/IP/设备/支付账户关联识别。
4. **证据校验**：照片反向搜索、历史工单比对、EXIF 检查。
5. **行为分析**：索赔节奏（短时间多单）、话术模板化、金额刻意踩线。

## 3. 处置标准

| 情形 | 处置 |
|---|---|
| 命中高风险规则 | 暂停自动退款，转人工复核 |
| 确认职业索赔 | 按规则正常处理（不因身份改变规则），拒绝超标准主张，留痕 |
| 确认调包 | 拒绝退换，商品退回用户，记录风控标签 |
| 确认伪造证据 | 拒绝赔付，标记账号，必要时报警 |
| 确认团伙 | 关联账号全部人工审核，上报风控 |
| 冒充客服诈骗（用户被骗） | 提示防骗、引导报警、平台出证明 |

原则：**对欺诈零容忍，但对正常用户零误伤**——规则命中只是「复核」，不是「拒绝」。

## 4. 与客服协作

- 客服不得告知用户「您被风控标记」，口径：「您的退款申请需要进一步审核，48 小时内给您答复」。
- 客服发现可疑行为（用户主动提出多账号、反复仅退款）→ 工单打风控标签。
- 风控结论回传客服，客服按结论执行，不自行扩赔。
- 客服自身防骗：绝不向用户索要密码/验证码，绝不私下转账。

## 5. 规则阈值速查

| 规则 | 阈值 |
|---|---|
| 生鲜高频退款 | 30 天 3 次 → 人工复核 |
| 生鲜退款金额 | 90 天累计 500 元 → 风控审查 |
| 高价值退货 | ≥ 2000 元 → 需质检报告 |
| 单笔现金赔偿 | > 1000 元 → 总经理审批 |
| 30 天累计赔偿 | > 2000 元 → 风控复核 |
| 退款率 | 用户退款率 > 30% → 关注 |
| 同 SKU 退货率 | 单周 > 8% → 品控排查 |

## 6. 数据与复盘

- 每周输出风控周报：拦截量、类型分布、误伤率（关键指标）。
- 每月调整规则阈值（识别新模式），调整需主管审批。
- 误伤案例必须复盘：误伤用户主动致歉 + 补偿。
- 欺诈损失计入商家保证金或追偿流程。

## 7. 话术要点

- 「您的退款申请已提交，我们会在 48 小时内完成审核，请耐心等待。」
- 「关于您提到的赔偿标准，我们按平台规则执行，需要进一步核实一下，稍后给您答复。」
- 「请勿向任何自称平台客服的人转账或提供验证码，平台不会要求您先付款再退款。」
- 禁止说「您被风控了」「我们怀疑您骗钱」——保持专业，不激化。
