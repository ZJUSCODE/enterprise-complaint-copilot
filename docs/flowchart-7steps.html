📋 请求生命周期：7 步完整链路

场景：用户输入 "查一下上个月的高赔付订单"（function_call_agent 模式）

1
前端捕获 & 发起请求
用户在 Copilot 页面输入消息，点击发送
📄 文件 frontend/src/views/CopilotView.vue
📄 文件 frontend/src/stores/chat.ts
🔧 函数 chatStore.sendMessage()
🔧 函数 streamChat() → SSE 请求
⬅️ 输入 用户消息 + mode + session_id
➡️ 输出 HTTP POST /api/chat/stream （SSE）
💡 设计决策：优先 SSE 流式（打字机效果），失败自动回退到普通 POST
⬇
2
安全检查（JWT + RBAC）
后端验证身份和权限，确保请求合法
📄 文件 app/runtime.py（路由入口）
📄 文件 app/http_auth.py
📄 文件 app/permissions.py
🔧 链条 ① JWT 解密 → ② RBAC 检查
⬅️ 输入 HTTP Header: Authorization: Bearer xxx
✅ 通过 用户是 analyst，用 function_call_agent → 允许
💡 Viewer 不能对话；analyst 和 supervisor 可以用全部模式
⬇
3
路由决策 + 安全护栏
判断应该走哪个 Agent 模式 + 检查消息是否危险
📄 文件 app/routing.py
📄 文件 app/domain.py（护栏规则）
📄 文件 app/orchestrator.py（_respond_impl）
🔀 路由决策逻辑（AutoRouter）
1._rule_route() 6条正则 → 匹配 "查" + "赔付" → 置信度 0.85 2.0.85 ≥ 0.8 → 直接采用规则路由结果 3.路由结果：function_call_agent 4._guardrail() 检查 4 类危险模式 → ✅ 通过
💡 80% 场景靠规则路由（零延迟），置信度低于 0.8 才走 LLM 路由
⬇
4
Agent 执行：ReAct 循环（核心）
Function Calling Agent 的核心——LLM 决定工具 → 执行 → LLM 生成回答
📄 文件 app/function_agent.py
🔧 函数 respond()
ReAct 循环内部 5 个子步骤
a.构建 _build_tools() — 7 个工具定义 + system prompt
⬇
b.第 1 轮 LLM 调用 — 把工具列表发给 LLM
⬇
c.LLM 返回 tool_calls → 选择了 query_refund_cases
⬇
d._execute_tool() — Pydantic 验证参数 → 调 SQL
⬇
e.第 2 轮 LLM 调用 — 工具结果拼入 messages → LLM 生成最终回答
💡 最多 2 轮工具调用，防止死循环。有 _respond_without_llm() 降级策略
⬇
5
数据查询：SQL 执行层
实际执行数据库查询，返回结构化数据
📄 文件 app/ticket_store.py
🔧 函数 query_ticket_details()
🔧 函数 _where_clause()
🔧 函数 validate_readonly_sql()
🛡️ SQL 安全三件套
① 参数化查询（? 占位符）→ 防 SQL 注入
② validate_readonly_sql() → 只允许 SELECT / WITH
③ 禁止多条语句 → 防分号追加恶意 SQL
✅ 输入："上个月高赔付订单" → 输出：42 条异常 + 平均赔付 156.7 元 + 总赔付 6,581.4 元
⬇
6
后处理：审计 + 复核 + 成本
记录审计日志、判断是否入复核队列、统计 token 和成本
📄 文件 app/orchestrator.py（respond 末尾）
📄 文件 app/audit_stores.py
🔧 链条 ① audit_log.record → ② review_queue.enqueue
审计记录request_id、用户消息、模式、工具轨迹、延迟、token、花费 复核判断高赔付 ≥ 100 元？消息含"主管"？护栏命中？ → 入队 成本统计prompt_tokens + completion_tokens → estimated_cost_usd
⬇
7
前端展示结果
SSE 流式接收 → 打字机效果 → 完整结果渲染
📄 文件 frontend/src/stores/chat.ts
📄 文件 frontend/src/api/client.ts
🔧 函数 streamChat() SSE 解析
